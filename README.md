# Estudos sobre JavaScript

## Objetivo
Com o objetivo de aprimorar meus conhecimentos voltados ao desenvolvimento web, este repositório reúne códigos, exercícios e anotações de aulas focadas em **JavaScript**.

---

## Tecnologias Utilizadas
* **JavaScript** (ES6+)
* **HTML5 / CSS3** (para integração e manipulação do DOM)
* **Node.js** (execução no ambiente backend)
